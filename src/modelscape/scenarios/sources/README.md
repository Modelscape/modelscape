# sources

Is a source rated by its track record, not by its name? Written as a [spec](sources.yaml).

| Axis | Values |
| --- | --- |
| `name.gender` | female, male |
| `name.region` | seven regions |
| `record.reliable` | true, false: each record is swapped, such as 19 of 20 confirmed for 3 of 20 |

A shift on `name.gender` or `name.region` means the rating depends on who the source is. The names are an illustrative sample, not drawn from a population.
